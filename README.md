### 📌 Featured Projects

#### [EduKE](https://github.com/MagetoJ/EduKE-)
Multi-tenant school management platform for Kenyan schools, built around the CBC curriculum framework.
- FastAPI + async SQLAlchemy backend, React/TypeScript (Vite) frontend
- Role-based access control across admin, HOD, teacher, and student dashboards
- Bulk onboarding via Excel, timetable builder with conflict detection, lesson planning tools

#### [Maria POS](https://github.com/MagetoJ/Maria-POS)
Point-of-sale system for bars and restaurants.
- React + Vite + TypeScript frontend, Node/Express/Knex backend
- Role-based waiter/clearance workflows built for real venue operations

#### Smartbiz Mobile App
Offline-first POS built as a PWA.
- IndexedDB-backed local storage with a sync engine (outbox draining, retry logic)
- Idempotent backend sync via client-generated UUIDs
